Расширение визитки из Лабы №1 динамическим поведением на jQuery.

## Что реализовано на jQuery
- 🍔 Выпадающее меню (бургер, `slideToggle`)
- ✉️ Форма обратной связи — валидация + симуляция отправки через `$.ajax()`
- 🪟 Модальное окно (закрытие по крестику, оверлею, Esc)
- 📦 Динамическая галерея из `data/portfolio.json` через `$.getJSON`
- 🎞 Анимации: `fadeIn`, `slideToggle`, `animate`, `fadeOut`
- 🎠 Карусель навыков (кнопки + автопрокрутка 3.5 сек)
- 🔦 Подсветка активного пункта меню при скролле
- ⬆️ Кнопка «Вверх» с плавным скроллом
- 🔊 Звук «вака-вака» на клики (опционально)
- 🕹 Аркадный счётчик очков

## Стек
- HTML5, CSS3 (Flexbox, Grid, media queries, анимации)
- jQuery 3.7 (CDN)
- JSON
